## What I'm Building

### [HybridCore](https://github.com/HybridMindLabs/HybridCore)

> A modular, self-hosted platform for gaming communities, server owners, and multiplayer projects.

HybridCore is the foundation of a growing product ecosystem. It combines a modern web application with installable extensions and cross-game bridges, allowing communities to manage content, users, engagement, rewards, and game-server actions from one platform.

**Core stack:** `Laravel` `PHP` `Vue.js` `TypeScript` `Blade` `SQL`

## HybridCore Ecosystem

### Platform Extensions

| Project | Purpose | Stack |
|---|---|---|
| **[Vote](https://github.com/HybridMindLabs/hybridcore-vote)** | Server voting, automated player rewards, and top-voter leaderboards | PHP · Vue |
| **[Staff](https://github.com/HybridMindLabs/hybridcore-staff)** | Public team pages with groups, roles, biographies, ordering, and social links | PHP · Vue |
| **[Giveaways](https://github.com/HybridMindLabs/hybridcore-giveaways)** | Eligibility rules, weighted entries, winner draws, notifications, and in-game rewards | PHP · Vue |
| **[ServerCast](https://github.com/HybridMindLabs/ServerCast)** | Send messages from the control panel to one, several, or every connected game server | PHP · Vue |

### Game-Server Bridges

HybridCore uses dedicated bridge plugins to deliver queued commands, rewards, messages, and moderation actions directly to game servers.

| Game / Platform | Integration | Language |
|---|---|---|
| Counter-Strike 1.6 / AMX Mod X | **[hybridcore-bridge-cs16](https://github.com/HybridMindLabs/hybridcore-bridge-cs16)** | Pawn |
| Rust / Oxide / uMod | **[hybridcore-bridge-rust](https://github.com/HybridMindLabs/hybridcore-bridge-rust)** | C# |
| FiveM | **[hybridcore-bridge-fivem](https://github.com/HybridMindLabs/hybridcore-bridge-fivem)** | Lua |
| Minecraft / Spigot / Paper | **[hybridcore-bridge-minecraft](https://github.com/HybridMindLabs/hybridcore-bridge-minecraft)** | Java |

This ecosystem demonstrates experience with:

- Modular application and extension architecture
- Cross-language and cross-platform integration
- Command queues and asynchronous workflows
- Automated rewards and event-driven features
- Administration interfaces and community-facing UX
- Self-hosted software and infrastructure-aware development
